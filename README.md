# 數學任務站｜AI 規則版

這是「數學任務站」的獨立、無登入靜態副本，保留傳統測驗、怪物對戰、收集精靈、提示、解析與兩階段補強流程。專案以 [`AGENTS.md`](AGENTS.md) 作為後續 AI 開發契約，讓新題庫、新模式與新頁面能遵循同一套規則持續擴充。

## 快速開始

```bash
npm run check
npm run serve
```

開啟 `http://localhost:4173/`。網站不要求帳號，作答資料留在目前瀏覽器。

Windows 已安裝 Chrome 時，可在本機伺服器啟動後執行 `npm run test:browser`，自動確認怪物對戰能載入題目、四個選項與對戰舞台。

## 專案特色

- 三種可切換學習模式：傳統測驗、怪物對戰、收集精靈。
- 七、八、九年級題庫，包含難度、提示與解析。
- 無登入、無信箱、無教師後台、無個資上傳。
- 自動驗證登入元件未被帶回、主要頁面存在、資源連結完整。
- `AGENTS.md` 明確規範題庫格式、檔名、版面、無障礙、驗證與部署流程。

## 隱私與網址限制

本版未建立站內登入頁。若部署為公開 GitHub Pages，任何取得網址的人都能查看，也可能被轉傳或被搜尋引擎發現；秘密網址不是安全的權限控管。需要真正限制存取時，請使用具備身分驗證與允許名單的私人主機。

## 來源與獨立性

本專案由既有「數學任務站」學習模式建立獨立副本；不使用原站的網域、資料庫、帳號系統或部署識別，亦不覆蓋原站內容。
